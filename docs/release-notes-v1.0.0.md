# v1.0.0 릴리즈 노트 초안

상태: 로컬 배포 후보 준비 완료, 미공개. 문서 공개와 별개로 버전·배포 코드 변경은 준비 중이며, 정식 버전 태그·릴리즈는 아직 게시하지 않았습니다.

QuestWeaver의 첫 정식 공개 버전으로 준비하는 Windows x64 로컬 퀘스트 기획 도구입니다. 퀘스트 원문 작성부터 플로우 편집·구조 검사·백업까지 한 PC에서 이어서 작업할 수 있습니다.

## 포함 기능

- 게임·지역별 퀘스트 관리와 검색, 수동 임시저장·등록
- 퀘스트 공통 및 단계별 기획 정보, 독립 스크롤 속성 패널
- 단계 크기·좌우형/상하형 연결점·직선/꺾은선/곡선 편집
- 실행 취소·다시 실행과 가로·세로 로컬 자동 배치
- 그래프 구조 검사, 상세 미리보기와 전체 차트 PNG 내보내기
- 사용자 OpenAI API 키 설정과 AI 초안 미리보기·적용·명시적 저장
- 버전 1 JSON 내보내기·새 퀘스트로 가져오기
- 한글 네이티브 메뉴, 백엔드 자동 실행·종료와 개발/설치 DB 분리

설치 대상 PC에 별도 Java·Node.js 설치는 필요하지 않습니다. 샘플 JSON·DB·API 키·보안 저장 파일은 첨부하지 않습니다. 공개 첨부 대상은 검증을 마친 해당 설치 파일과 선택적으로 체크섬 파일뿐입니다. 구버전 0.1.0 설치 파일·win-unpacked·builder-debug·테스트 이미지·사용자 데이터는 첨부 대상이 아닙니다.

## 사용 전 안내

신규 프로필은 빈 퀘스트 목록과 키 미등록 상태에서 시작합니다. 기존 프로필의 작업은 초기화하지 않습니다. README 화면의 퀘스트는 사용 예시이며 설치 파일에 포함되지 않습니다.

AI 생성 시 저장된 퀘스트 원문을 OpenAI로 전송하고 본인의 API 계정에 비용이 청구됩니다. ChatGPT 구독과 API 과금은 별개입니다. AI 결과는 검토·수정할 초안이며, 구조 검사는 게임 실행이나 자유 입력 조건의 의미까지 검증하지 않습니다. 키 없이 수동 기능을 사용할 수 있습니다.

## 호환성과 한계

- 과거 수동 곡선이 현재 단일 3차 베지어 표시에서 일부 다르게 보일 수 있습니다.
- 자동 배치는 복잡한 그래프의 모든 선 교차·문구 겹침을 제거하지 않습니다.
- 코드 서명이 없고 기본 Electron 아이콘을 사용합니다.
- 현재 후보의 Java 21.0.2는 최신 보안 패치 수준이 아닙니다. 정식 공개 전 최신 보안 업데이트가 적용된 Java 21로 다시 빌드·검증하고 크기·해시를 갱신해야 합니다.

## 검증 범위와 공개 전 남은 작업

Windows에서 개발 바이너리와 최종 win-unpacked 바이너리를 임시 H2·프로필로 자동 검증했습니다. **별도 Windows 사용자/VM에서 NSIS를 실제 설치한 검증은 하지 않았습니다.** 개발 앱과 win-unpacked 실행을 설치 검증으로 간주하지 않습니다. 이번 작업에서는 유료 AI API를 호출하지 않았으며, 사용자가 기존 개발 앱에서 실제 생성·적용·저장을 확인한 사실은 설치 앱 검증과 별개입니다.

[검증 결과와 실제 설치 확인 순서](release-validation-v1.0.0.md)를 완료한 뒤 공개 여부를 결정합니다. 이 초안에는 아직 존재하지 않는 다운로드 주소를 넣지 않았습니다.
